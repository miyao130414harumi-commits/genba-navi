2級管工事 模擬1回目 徹底解説

チャットでやったNo.3・No.7・No.11の掘り下げスタイルで全52問。各問「仕組み → 引っかけ → 他の選択肢 → つながり」の流れで書いてある。

No.1 湿り空気 — 答え(4)

空気をあたためても、中の水分の量は1グラムも変わらない。この一点がわかれば解ける。

まず3つの言葉を整理

絶対湿度 = 空気の中に実際に入ってる水分の量(乾き空気1kgあたり何kg)。水そのものの量。
相対湿度 = 「その温度で持てる水分の上限」に対して今何%か。コップの水位みたいな割合の話。
飽和 = 上限いっぱい=相対湿度100%。もうこれ以上水蒸気を持てない状態。

加熱すると何が起きるか

温度が上がると「持てる上限」だけが増える。コップが大きくなるイメージ。中の水の量(絶対湿度)はそのままだから、割合(相対湿度)だけが下がる。ドライヤーで髪が乾くのは、温風の相対湿度が低くて水分を吸いやすいからで、空気の水分が減ったわけじゃない。

問題文の引っかけ
(4)は「加熱すると絶対湿度は下がる」。下がるのは相対湿度。用語のすり替え。

他の選択肢
- (1)○ 飽和=100%。定義そのまま
- (2)○ 絶対湿度の定義そのまま
- (3)○ 飽和状態では蒸発が起きない→気化熱で温度が下がらない→乾球=湿球

つながり:No.8の空気線図で「加熱=真横に移動」なのは、まさに絶対湿度が変わらないから。この2問はセット。

No.2 空気環境 — 答え(3)

居室の必要換気量の基準はCO₂(二酸化炭素)。これを一酸化炭素(CO)にすり替えるのが定番の引っかけ。

なぜCO₂が基準なのか

人がいれば呼吸で必ずCO₂が出る。つまりCO₂濃度は「この部屋、人の割にどれだけ空気を入れ替えてるか」のバロメーターとして使える。許容値は1,000ppm。学校やオフィスのCO₂モニターもこの発想。

COは何者か
一酸化炭素は不完全燃焼で出る毒ガス。基準値は10ppmと別にあるけど、「換気量を算出する基準」ではない。人がいるだけでは発生しないから、部屋の混み具合の指標にならない。

他の選択肢
- (1)○ 浮遊粉じんは呼吸器系に影響
- (2)○ 臭気は臭気強度・臭気指数で表す
- (4)○ ホルムアルデヒド=シックハウスの原因物質。目や呼吸器を刺激

覚え方:「居室の換気=CO₂=1,000ppm」。CO₂とCOは字面が似てるだけの他人。

No.3 流体 — 答え(1)

登場する3つの圧力

静圧 = 流れに関係なく、四方八方に押す圧力。風船の中の空気が内側から壁を押してるあの力。ダクトや配管の中なら「壁を押してる圧力」。止まってる流体でも持ってる。

動圧 = 流れの勢いそのものの圧力。扇風機の前に手をかざすと押される感じ、あれが動圧。流れが速いほど大きい(速度の2乗に比例)。止まってたらゼロ。

全圧 = この2つの合計。

全圧 = 静圧 + 動圧

つまり「壁を押す力」+「進む勢い」=その流体が持ってる圧力の全部、ってこと。

問題文の引っかけ
選択肢(1)は「全圧=静圧+位置圧」って言ってる。位置圧(高さのエネルギー)はベルヌーイの定理に出てくる別のメンバーで、全圧の式には入らない。もっともらしい言葉のすり替え。

選択肢(3)のピトー管とセットで覚えると強い
ピトー管は流速を測る器具だけど、仕組みはこう:
1. 流れの正面に向けた穴で「全圧」を測る
2. 流れと平行な穴で「静圧」を測る
3. 引き算すると → 全圧−静圧=動圧
4. 動圧がわかれば流速が計算できる

つまりピトー管は「全圧=静圧+動圧」の式をそのまま道具にしたもの。(1)と(3)は同じ知識で解ける仲良し選択肢。

他の選択肢
- (2)○ 水は空気よりネバい(粘性係数大)
- (4)○ レイノルズ数大=乱流

つながり:No.38「ダクト内の風量は風速を測定して求める」の測定器がまさにピトー管。

No.4 伝熱 — 答え(2)

熱の移動量は温度差に比例する。式で書くと q=α×A×Δt。αが熱伝達率、Aが面積、Δtが温度差。

直感で考える

アツアツのお風呂(80℃)と冷たい水(10℃)を隣り合わせたら、熱はドバドバ移動する。30℃と25℃ならちょろちょろ。温度差が大きいほど熱が流れる勢いが強い。冬に窓を触ると冷たく感じるのも、体温と窓の温度差が大きくて熱がガンガン奪われるから。

問題文の引っかけ
(2)は「温度差に反比例」。真逆。伝熱の式は熱伝導も熱伝達もぜんぶ「温度差に比例」なので、「反比例」と書いてあったらほぼ誤り選択肢と思っていい。

他の選択肢
- (1)○ 熱伝導=物体の内部で高温→低温へ伝わる現象。定義通り
- (3)○ 熱伝導率は材料固有の値。銅は伝わりやすい、グラスウールは伝わりにくい(だから保温材)
- (4)○ 熱力学第二法則。冷たい方から熱い方へ勝手には移らない。移せるのはヒートポンプみたいに仕事を加えたときだけ

つながり:(3)の「熱伝導率は材料固有」はNo.25の保温材の話の土台。伝導率が小さい材料=保温材。

No.5 電気設備の記号 — 答え(4)

正しい対応表

  • F = ヒューズ(Fuse)
  • FEP = 波付硬質合成樹脂管(地中埋設用の電線管。ジャバラのやつ)
  • VT = 計器用変圧器(Voltage Transformer。高圧を計器で測れる電圧に落とす)
  • SC = 電力用コンデンサ(Static Capacitor。力率改善に使う)
  • 2E = 過負荷欠相継電器(モーター保護のリレー)

問題文の引っかけ
(4)は「SC=過負荷欠相継電器」。SCはコンデンサで、過負荷欠相は「2E」。記号と名称のペア入れ替え。

覚えるコツ
SCのCはCapacitor(コンデンサ)のC、と英語の頭文字で紐付けると忘れない。2Eは「2つのError(過負荷Overloadと欠相Open-phase)を見る」と覚える人が多い。

つながり:2級電気施工の勉強とモロ被りの知識。管工事の試験に電気記号が出るのは、現場で電気屋さんと図面をやりとりするから。両方の資格を狙うなら二度おいしい問題。

No.6 コンクリート工事 — 答え(1)

水セメント比(W/C)とは

コンクリートに入れる水÷セメントの重さ。この数字が大きい=水が多い=シャバシャバの薄いコンクリ。

なぜ水が多いと弱いのか
カルピスと同じで、薄めるほど「濃さ」が下がる。しかも余分な水は固まったあと蒸発して、その跡が細かい空隙(スカスカの穴)になる。だからW/Cが大きいほど圧縮強度も耐久性も落ちる。強いコンクリが欲しければW/Cを小さくする。

問題文の引っかけ
(1)は「W/Cが大きくなると圧縮強度も大きくなる」。真逆。「大きく」つながりで直感を騙しにきてる。

他の選択肢
- (2)○ コンクリは水和反応(化学反応)で固まる。気温が高い=反応が速い=早く固まる
- (3)○ 打継ぎは構造の弱点になるので、せん断力が小さい梁中央付近に設ける(端部はせん断力が大きい)
- (4)○ 横流しすると重い砂利が沈んで材料分離するのでNG。打ちたい場所に直接落とす

つながり:2級建築施工の勉強と共通の頻出論点。「W/C大→強度小」は建築でも管でも毎年出るレベル。

No.7 空調の省エネ計画 — 答え(4)

まず大前提:外気は"熱のコスト"

空調は室内の空気をぐるぐる回して温度調整するのが一番ラク。でも人がいる部屋はCO₂が溜まるから、外気を入れなきゃいけない。ここで問題なのが、外気は空調的には"招かれざる客"ってこと。

  • 夏:35℃の熱風を26℃まで冷やさなきゃいけない
  • 冬:5℃の冷気を22℃まで温めなきゃいけない

つまり外気を入れるほどエネルギーを食う。店のドアを開けっ放しで冷暖房をガンガンかけてる状態と同じ。

選択肢を見ていくと

  • (1)○ 全熱交換器 = 捨てる排気の熱を、入ってくる外気に乗せ換える装置。冬なら「暖かい排気」で「冷たい外気」を予熱してから入れる。熱のリサイクル
  • (2)○ 高効率機器 = 燃費のいい機械を使う。そのまんま
  • (3)○ 熱源の複数台分割 = デカい1台だと軽負荷の春秋も大出力機を低効率で回すハメになる。小分けなら「今日は1台だけ運転」ができる。コンビニに大型トラックで行くか軽で行くかの違い
  • (4)✕ 暖房時に外気導入を多く = 冷たい外気をたくさん入れたら、その分よけいに加熱が必要。省エネと真逆

応用の一歩先
例外として、中間期(春秋)の冷房だけは外気を多く入れるのが省エネになる(外気冷房=涼しい外気でタダで冷やす)。「暖房時に多く」は✕、「涼しい時期の冷房に多く」は○。ここまで押さえると応用問題でも崩れない。

No.8 空気線図とシステム図の対応 — 答え(3)

線図の読み方(これだけ覚える)

  • 横軸=温度(右ほど暖かい)、縦軸=絶対湿度(上ほど水分が多い)
  • 加熱 → 水分は増えないから真横に右(No.1の知識そのまま)
  • 蒸気加湿 → 温度ほぼそのままで水分だけ増える→真上
  • 混合 → 2つの空気を混ぜると、2点を結んだ線の途中に落ちる

暖房の流れを追う

  1. 外気(b)と部屋からの還気(a)を混ぜる → 線上の点c(混合点)
  2. 加熱コイルで温める → cから真横に右へ移動 → d
  3. 加湿器で蒸気を足す → dから真上へ → e
  4. eが給気(SA)として部屋へ

つまりdは「加熱が終わって、加湿がまだの空気」。システム図で言えば加熱コイルの出口・加湿器の入口=③。

解き方の手順(毎年これで解ける)
1. 線図の矢印の向きで「何をしたか」判定(真横=加熱、真上=加湿、線上=混合)
2. 聞かれてる点が「何の後・何の前」かを言葉にする
3. システム図の機器の並び順に当てはめる

引っかけポイント
④(加湿後=e)と間違えやすい。dとeは縦に並んでて、「dは下(乾いてる方)=まだ加湿してない」という位置関係を見る。冷房バージョン(冷却=左へ、除湿=左下へ)でも手順は同じ。

No.9 熱負荷 — 答え(1)

顕熱と潜熱の見分け方は「水蒸気を運ぶか?」

顕熱 = 温度を変える熱。温度計に出る。
潜熱 = 水蒸気が持ってる熱。湿度に効く。

だから判定はシンプルで、「その負荷は部屋に水蒸気を持ち込むか?」を考えるだけ。

  • 日射 → 太陽の光と熱がガラス越しに入るだけ。水蒸気ゼロ → 顕熱のみ
  • 照明・OA機器 → 乾いた発熱 → 顕熱のみ
  • 人体 → 汗と呼気で水蒸気を出す → 顕熱+潜熱
  • 外気・隙間風 → 湿った空気そのものが入る → 顕熱+潜熱

問題文の引っかけ
(1)は「日射負荷には顕熱と潜熱がある」。日射は水蒸気を運ばないので潜熱はない。

他の選択肢
- (2)○ 外気負荷は顕熱+潜熱(上の通り)
- (3)○ SHF(顕熱比)=顕熱負荷÷全熱負荷。定義そのまま
- (4)○ 冷房負荷・暖房負荷はそれぞれ顕熱と潜熱を持つ

つながり:潜熱の正体は「水の蒸発・凝縮の熱」。No.1の湿り空気、No.8の加湿(=潜熱を足す操作)と全部同じ世界の話。

No.10 空気清浄装置 — 答え(4)

フィルタの大原則:空気はゆっくり通す

フィルタでゴミを捕まえる仕組みを想像すると、通過速度を速くするのがなぜダメか見えてくる。

  1. 圧力損失が増える:狭いところを速く通そうとするほど抵抗は大きくなる。ストローを勢いよく吸うほど苦しいのと同じ
  2. 捕集効率が落ちる:粒子が繊維に捕まる前に、勢いで突き抜けてしまう

つまり(4)「通過速度を速くすることで圧力損失を小さくしている」は二重にウソ。実際のフィルタ設計は逆で、ろ材の面積を広く取って(ジグザグに折って)通過速度を遅くしている。

他の選択肢
- (1)○ 静電式(電気集じん機)は一般空調用。タバコの煙とかに強い
- (2)○ ろ過式は粗じん用〜中性能〜HEPA(クリーンルーム用)まで幅広い
- (3)○ 粒子捕集の原理:遮り・慣性・拡散・静電気。「遮り、静電気等」は正しい

現場イメージ:フィルタが目詰まりすると圧損が増えてファンの電気代が上がる。だから定期交換する。「速度と圧損はトレードの関係」という感覚は実務でもそのまま使う。

No.11 コールドドラフトの防止 — 答え(2)

まずコールドドラフトって何?

冬、暖房してる部屋でも窓際に立つとスースー寒いことあるでしょ。あれ。

  1. 窓ガラスは断熱が弱いから、内側の表面がキンキンに冷えてる
  2. 窓際の空気がガラスに冷やされる
  3. 冷えた空気は重いから、窓に沿って下に滑り落ちる
  4. 冷気が床を這って足元に流れてくる → 「暖房してるのに足元だけ寒い」

隙間風がなくても起きる。窓が"冷気の滝"になるイメージ。

選択肢を見ていくと

  • (1)○ 自然対流形の放熱器は、表面がアツアツすぎると急激な上昇気流→どこかで強い下降流も生まれる。温度差をマイルドにして空気をゆるやかに動かす
  • (2)✕ 放熱器は内壁側に設置 = 冷気の発生源は窓=外壁側。内側の壁に置いたら冷気の滝は野放し。正解は外壁側の窓下に置いて、放熱器の上昇気流で落ちてくる冷気を真下で迎え撃つ。昔の学校や病院で窓の下にヒーターが並んでたのはこれが理由
  • (3)○ エアフローウィンドウ=二重ガラスの間に室内空気を流す窓。ガラス面が冷えにくい=冷気の滝がそもそも発生しにくい
  • (4)○ 気密を上げて隙間風(冷気の直接侵入)を減らす

整理:対策は2系統
「発生させない」(窓の断熱・気密=(3)(4))と「発生した冷気を打ち消す」(窓下に放熱器=(1)と(2)の正しい姿)。(2)だけが打ち消す装置を関係ない場所に置いてる。

引っかけの型:場所の入れ替え(外壁側⇔内壁側)。No.20の上流⇔下流と同じパターン。

No.12 空冷ヒートポンプパッケージ — 答え(3)

冷媒配管には物理的な限界がある

屋内機と屋外機は冷媒配管でつながってて、この配管の長さ・高低差には制限がある。理由は2つ。

  1. 能力低下:配管が長い・高低差が大きいほど、冷媒を運ぶのに圧力を食われて冷暖房能力が落ちる
  2. オイル戻り:圧縮機の潤滑オイルは冷媒と一緒に配管を旅する。高低差がありすぎるとオイルが圧縮機に帰ってこられず、焼き付きの原因になる

だから(3)「高低差には制限がない」は言い過ぎで誤り。機種ごとにカタログに「最大配管長○m、最大高低差○m」と必ず書いてある。

他の選択肢
- (1)○ 冷房時、外気温が高いほど屋外機が熱を捨てにくい→運転効率低下。猛暑日にエアコンの効きが悪いのはこれ
- (2)○ 冷暖同時型=冷房してる部屋から回収した熱を、暖房したい部屋に回すマルチ。実在する
- (4)○ 暖房時は屋外機コイルが冷たくなる→外気の水分が霜になる。だからデフロスト(霜取り)運転がある

試験テクニック:「制限がない」「〜によらず」「影響しない」みたいな断定表現は疑ってかかる。No.22・No.50(4)も同じ型。

No.13 換気の対象室と要因 — 答え(1)

部屋ごとに「何のために換気するか」が違う

  • 電気室 → 変圧器などの機器が発熱する → 熱の除去
  • ボイラー室 → 燃やすには酸素が要る → 燃焼空気の供給
  • シャワー室 → 湯気だらけ → 湿気(カビ・結露防止)
  • 書庫 → 古い紙の臭いや保存環境 → 臭気
  • 駐車場 → 排気ガス → 汚染物質

問題文の引っかけ
(1)は「電気室—汚染物質」。電気室で問題になるのは機器の発熱で、熱がこもると変圧器の寿命が縮む・故障する。汚染物質は駐車場や作業場の話。

覚え方
部屋の中で何が起きてるか想像すればいい。電気室に入ると機械がブーンと唸ってムワッと暑い。あの暑さを逃がすのが換気の仕事。丸暗記じゃなく「その部屋の困りごとは何?」で考えると、初見の組合せでも対応できる。

No.14 換気 — 答え(3)

必要換気量=外気の量。ここがすべて

換気の目的はCO₂や汚染物質を薄めること。薄めるには外の新鮮な空気と入れ替えるしかない。部屋の中の空気をいくらぐるぐる循環させても、CO₂の総量は1ミリも減らない。サーキュレーターを何台回しても換気にならないのと同じ理屈。

だから「必要換気量」と言ったら、それは取り入れる外気の量そのもの。(3)の「室内を循環する空気量で、外気は含まれない」は定義の真逆。

他の選択肢
- (1)○ 自然換気=温度差による浮力(暖かい空気は上に抜ける)や風力で動かす
- (2)○ 機械換気=送風機で強制的に入れ替える

No.22 ガス設備 — 答え(3)

ガスの比重はノズル噴出量に影響「する」

  • ③ = A経由なら4日、ダミー経由(Bの後)なら5日 → 遅い方で5日
  • ④ = 5+C(3) = 8日
  • ⑤ = 8+E(2) = 10日
  • ⑥ = D経由なら5+4=9日、F経由なら10+3=13日 → 13日
  • ⑦ = G経由なら10+4=14日、H経由なら13+3=16日 → 16日

クリティカルパス(最長経路)は B→ダミー→C→E→F→H = 5+3+2+3+3 = 16日。(2)の「15日」が誤り。

他の選択肢を検証
- (1)○ Hはイベント⑥から出る作業。⑥に入るDとFの両方が完了しないと開始できない
- (3)○ Dを2日短縮してもD経由は7日。⑥を決めてるのはF経由の13日のままなので全体は変わらない(Dには余裕=フロートがある)
- (4)○ Gの最早開始は10日、最遅開始は16−4=12日。2日遅らせても全体に影響しない

試験テクニック:計算する前に「クリティカルパスの日数」の選択肢から検証すると速い。合ってなければそれが答え、合ってたら他を見る。

No.31 品質管理 — 答え(2)

「品質を上げるとカネがかかる」は直感のワナ

品質管理をちゃんとやると何が起きるか、順を追うと:

  1. 施工中に不良を早期発見できる
  2. 手直し(やり直し工事)が減る
  3. やり直しの材料費・人件費・工期遅延が消える
  4. 結果、原価は下がる

建設で一番高くつくのは「作ったものを壊してもう一回作る」こと。品質管理のコストは、手直し1回の損失に比べたら安い保険。(2)「品質は向上するが、手直しが増加し原価が上がる」は因果が逆で誤り。手直しは増えるんじゃなく減る。

他の選択肢
- (1)○ 品質管理の目的=設計図書等で要求された品質を満足するように施工すること
- (3)○ PDCA(Plan計画→Do実施→Check確認→Action処置)の繰り返し=デミングサークル
- (4)○ 主要機器の試験・防火区画の貫通処理は全数検査。命や防火に関わる箇所は抜き取りじゃダメ

身近な例:事務作業でもチェックをサボってミスが出ると、訂正と信頼回復のコストの方がはるかに高くつく。あれと同じ構造。

No.32 建設工事の安全管理 — 答え(1)

通勤災害は「家⇔職場」だけじゃない

労災保険の通勤災害がカバーする移動は3パターン:

  2. 就業場所⇔他の就業場所(ダブルワークの移動)
  3. 単身赴任先⇔帰省先の住居間

(1)「就業場所から他の就業場所へ移動する途中の災害は通勤災害に該当しない」は、2番を否定してるので誤り。かけもちで働く人が増えた時代に合わせた保護規定。

実務メモ
かけもちで働く人のための制度そのもの。A社の仕事を終えてB社へ向かう途中のケガも通勤災害の対象になりうる。

他の選択肢
- (2)○ 軟弱地盤での移動式クレーンは鉄板等を敷いて転倒防止。地盤ごと傾いて倒れる事故が実際に多い

No.33 機器の据付け — 答え(2)

飲料用タンクは「6面点検」

なぜ上だけ広いのか
タンク上部のマンホールから人が中に入って点検・清掃するから。60cmでは人がかがんで作業できない。1mあれば蓋を開けて出入りできる。

- (3)○ 機器を据えるコンクリート基礎は水平に仕上げる
- (4)○ 洗面器のコンクリート壁固定はエキスパンションボルト又は樹脂製プラグ

No.34 配管・配管附属品の施工 — 答え(1)

排水管の継手は「段差ゼロ」が命

排水は重力だけでダラダラ流れる、圧力のない流れ。管の内側にわずかな段差や出っ張りがあると、そこに髪の毛や汚物が引っかかり、雪だるま式に詰まる。

だから排水系統にはねじ込み式排水管継手(ドレネージ継手)を使う。内面がツライチ(段差なし)で、横管接続部には排水勾配まで考慮された排水専用設計。

溶接式継手はなぜダメか
鋼製突合せ溶接式管継手は給水・蒸気などの圧力配管用。溶接部の内面に段差やビード(溶接の盛り上がり)ができうるし、そもそも排水に必要な「流れやすさへの配慮」がない。(1)は誤り。

他の選択肢
- (2)○ 塩ビライニング鋼管の仕切弁は管端防食ねじ込み形(切断面の鉄がむき出しになる部分の錆び対策)
- (3)○ 突合せ溶接は開先加工+ルート間隔保持(溶接をちゃんと溶け込ませる基本)
- (4)○ 耐火二層管の接合=接着接合、ゴム輪接合(伸縮継手用)

設計思想:圧力配管は「漏れない」が正義、排水配管は「引っかからない」が正義。使う継手が違うのは正義が違うから。

No.35 ダクト・ダクト附属品の施工 — 答え(2)

スパイラルダクト差込接合の3点セット

  1. 継手にシール材を塗る
  2. 差し込んでビスで固定
  3. 上からダクト用テープを二重巻き(2回巻き)

(2)は「1重巻き」と言ってるので誤り。1回巻きでは気密が不十分で空気が漏れる。「シール・ビス・テープ二重」を作業手順の呪文として体で覚える。

他の選択肢
- (1)○ 防火ダンパーの支持は原則4点吊りだが、長辺300mm以下の小型は2点吊りでOK。FDは火災時に確実に閉まる必要があるから支持が厳重
- (3)○ 厨房排気フードの吊りは4隅+1,500mm以下の間隔。油でどんどん重くなるから支持多め
- (4)○ 浴室排気ダクトは湿気→結露水が出る前提で、排気ガラリに向けて下がり勾配 or 水抜きを設ける(水の逃げ道を作る)

現場イメージ:ダクトの気密が甘いと、設計風量が末端まで届かず「この部屋だけ空調効かない」クレームになる。テープ二重巻きはそのための保険。

No.36 保温・塗装 — 答え(4)

「動くための部品」は保温しない

防振継手は、ポンプの振動が配管に伝わらないように吸収する、わざとグニャグニャに作られたゴムの部品。これを保温材でガチガチに固めたら?

→ 動けなくなって振動を吸収できない。本末転倒。

だから防振継手・伸縮継手・フレキみたいな「動くことが仕事の部品」は原則保温しない。(4)「給水ポンプ回りの防振継手は原則として保温を行う」は誤り。

他の選択肢
- (1)○ 保温の厚さ=保温材のみの厚さ。補助材・外装材は含まない(保温性能を出すのは保温材本体だから)
- (2)○ 相対湿度85%以上では原則塗装しない。塗料が乾かない・密着不良になる
- (3)○ 冷水配管を吊りバンドで直接支持する場合は合成樹脂製支持受け。金属で直接触れると、そこが熱橋になって結露する

つながり:No.33(1)の耐震ストッパーも「動く部品(防振ゴム)への配慮」の話。「この部品は動きたいのか、動いてほしくないのか」で考えると据付け系の問題は整理できる。

No.37 渦巻ポンプの試運転調整 — 答え(3)

軸封装置は2種類。正常の姿が正反対

ポンプの回転軸が胴体を貫くところは、放っておくと水が漏れる。ここを塞ぐのが軸封装置。

グランドパッキン = 紐状のパッキンを軸に巻いて押さえる古典的な方式。完全に締め切ると摩擦熱で焼けるので、わざと少量ポタポタ漏らして冷却・潤滑する。滴下してるのが正常。

メカニカルシール = バネで密着させる精密な機械式シール。ほぼ無漏れが正常。ポタポタ垂れてたらシール面の摩耗=故障のサイン。

(3)「メカニカルシール部からの水滴の滴下が一定量継続してあることを確認」は、パッキンの正常をメカに当てはめたすり替えで誤り。

他の選択肢
- (1)○ 手で回して回転むら(異物噛み・軸曲がり)がないか確認
- (2)○ 瞬時運転で回転方向確認。三相モーターは結線次第で逆回転する。逆だと水が出ない
- (4)○ 軸受温度が周囲空気温度より過度に高くないか確認(異常発熱=軸受不良)

覚え方:「メカ=ドライ、パッキン=ウェット」。逆に書いてあったら誤り。

No.38 風量調整 — 答え(3)

風量調整は「全開スタート→絞る」

風量調整(TAB)の手順は、まず給排気口のシャッターや分岐部のダンパーをすべて全開にして送風機を回し、各吹出口の風量を測る。設計より多い系統を少しずつ絞って、全体のバランスを取っていく。

全閉スタートがなぜあり得ないか
1. 風がどこにも流れない=測定も調整もできない
2. 送風機が締切運転になり、過熱・サージングの危険

(3)「シャッターやダンパーを全閉にした後に行う」は常識レベルでおかしい誤り。

他の選択肢
- (1)○ 吹出口・吸込口の風量測定は補助ダクトで気流を整えてから測る(乱れた気流では正しく測れない)
- (2)○ ダクト内の風量=風速を測って断面積を掛ける。測定器はNo.3のピトー管
- (4)○ 機器の試験成績表・ダクト図・風量計算書を照らし合わせて調整

つながり:No.3(ピトー管で動圧→流速)がここで実務に着地する。理論と現場がつながる気持ちいいライン。

No.39 労働安全衛生法 — 答え(3)

酸素の数字は命に直結

  • 通常の大気:約21%
  • 酸欠防止の法定基準:18%以上を保つよう換気
  • 16%前後:頭痛・吐き気などの症状
  • 12%以下:めまい・筋力低下、10%以下は意識喪失〜死亡レベル

(3)「酸素の濃度を15%以上に保つように換気」は、法定の18%を下回る危険な数字で誤り。15%は「基準クリア」じゃなく「もう症状が出る領域」。

なぜ管工事でこれが重要か
ピット・マンホール・タンク内・排水槽は管工事の日常。酸欠事故は「入った本人+助けに入った人」が連鎖的に倒れる二次災害が典型で、毎年死者が出てる。数字の暗記というより、現場に入る前の測定を怠らないための知識。

他の選択肢
- (1)○ 作業内容変更時は安全衛生教育を行う
- (2)○ 移動はしごの幅は30cm以上
- (4)○ 可燃性ガス・酸素の容器は温度40度以下に保つ

引っかけの型:数字の入れ替え(18→15)。ただしこれは間違えると命に関わる数字なので、語呂じゃなく意味で覚えて。

No.40 労働基準法 — 答え(2)

「賃金」の定義は名前を問わない

労基法の賃金=「賃金、給料、手当、賞与その他名称の如何を問わず、労働の対償として使用者が労働者に支払うすべてのもの」。

ポイントは「名称の如何を問わず」。ボーナスと呼ぼうが寸志と呼ぼうが、働いた対価として払うものは全部賃金。だから賃金のルール(全額払い・直接払いなど)が適用される。(2)「賞与はこれに含まれない」は条文の真逆で誤り。

他の選択肢
- (1)○ 出来高払制でも労働時間に応じた一定額の賃金保障が必要(成果ゼロでも働いた時間分は守る)
- (3)○ 未成年者の賃金を親権者・後見人が代わって受け取るのは禁止(搾取防止。歴史的経緯のある条文)
- (4)○ 非常時払い:労働者が疾病等の費用に充てるため請求したら、支払期日前でも既往の労働分は支払う

実務メモ
給与計算の実務では、この「名称を問わず全部賃金」の感覚が土台になる。手当の名前を変えても法的性質は変わらない。

No.41 建築基準法(用語) — 答え(1)

居室の定義を分解する

居室=居住・執務・作業・集会・娯楽その他これらに類する目的のために継続的に使用する室

判定は2段階:
1. 目的が「居・執・作・集・娯」に当てはまるか
2. 継続的に使うか

カラオケルーム、ゲームセンター、映画館の客席…娯楽のために人がずっといる部屋は全部居室。(1)「娯楽のために継続的に使用する室は居室ではない」は定義に真っ向から反して誤り。

居室じゃないのは?
トイレ・浴室・洗面所・納戸・廊下・玄関=用は足すけど「一時的にしかいない」場所。継続性で切る。

なぜ居室かどうかが大事か
居室と認定されると採光・換気・天井高などの基準が適用される。人がずっといる場所だから環境を法で守る、という思想。飲食店やカラオケ店の部屋も多くは居室扱いで、換気設備の基準がかかってる。

他の選択肢
- (2)○ 避雷針は建築設備
- (3)○ 金属板・ガラスは不燃材料
- (4)○ 主要構造部が耐火構造=耐火建築物

No.42 建築基準法(配管設備) — 答え(2)

雨水立て管は一匹狼

雨水排水立て管は単独配管が原則。誰とも兼用しない。

汚水管と兼用したら:ゲリラ豪雨で管が雨水で満杯→行き場を失った汚水が逆流して、最悪トイレから噴き出す。
通気管と兼用したら:雨水が流れてる間、通気の通り道が水で塞がる→排水時の空気の逃げ場がなくなり、トラップの封水が吸い出されて破封→下水臭が室内へ。

どっちと組んでもろくなことがないので、雨水は自分専用の管を持つ。(2)「汚水排水管若しくは通気管と兼用してもよい」は誤り。

他の選択肢
- (1)○ 給水立て主管から各階への分岐管には止水弁(階ごとにメンテできるように)
- (3)○ 水栓の開口部は流し台のあふれ面と垂直距離を保つ=吐水口空間。No.17と同じ逆流防止
- (4)○ 排水設備の汚水に接する部分は不浸透質の耐水材料

つながり:No.20(通気の役目=封水を守る)がわかってると、「通気管と兼用がなぜダメか」が理屈で導ける。

No.43 建設業法(主任技術者の要件) — 答え(2)

資格には「担当業種」がある

主任技術者になれる要件は業種ごとに決まってる。管工事なら:

  • 2級管工事施工管理技士(第二次検定合格) → ○
  • 管工事に関し実務経験10年以上 → ○
  • 建築設備士となった後、管工事1年以上の実務 → ○
  • 技術士(該当部門) → ○

一級建築士はなぜダメか
一級建築士は建築士法の資格で、建設業法上は「建築一式工事」等の技術者要件。設計の最高峰資格ではあるけど、管工事の施工の技術者資格ではない。「偉い資格だから何でもできそう」という印象を突いた引っかけ。(2)が該当しない=正解。

覚え方
「資格と業種のペア」で見る。電気工事士→電気工事、建築士→建築工事、管工事技士→管工事。畑違いの偉い資格が混ざってたらそれが答え。

モチベ的つながり:この試験(第一次)に受かって第二次まで取れば、自分自身が(1)の要件で主任技術者になれる。受験者にとっては未来の自分の話。

No.44 建設業法(標識) — 答え(3)

現場の看板(建設業の許可票)に載せるもの

  • 商号又は名称
  • 代表者の氏名
  • 一般建設業/特定建設業の別
  • 許可番号・許可年月日・業種
  • 主任技術者(監理技術者)の氏名

現場代理人はなぜ載らないか
現場代理人は「請負契約の履行のために現場に置く、契約上の代理人」。公共工事の契約書(約款)で決まる存在で、建設業法の標識制度とは別の枠組み。法律が標識に求めてるのは「この現場は誰の許可でどの技術者が施工してるか」の公示であって、契約実務の担当者名じゃない。(3)「現場代理人の氏名」は定められていない=正解。

混同しやすいペア
- 主任技術者 = 建設業法上の技術者 → 標識に載る
- 現場代理人 = 契約上の代理人 → 標識に載らない

同じ人が兼務することも多いから現場感覚だと混ざりやすい。「法律の人は載る、契約の人は載らない」で切る。

No.45 消防法(屋内消火栓設備) — 答え(4)

消防設備に非常電源はセット

火事のとき何が起きるかを想像する:火災→電線が焼ける・ブレーカーが落ちる→停電。この状況でポンプが止まったら消火栓はただの飾り。だから屋内消火栓設備には、1号・2号を問わず非常電源(蓄電池設備・自家発電設備など)の附置が必要。

(4)「1号消火栓以外の場合は、非常電源の附置は不要」なんて例外はない。誤り。

他の選択肢
- (1)○ 消火栓箱の上部に赤色の灯火(位置表示灯)。停電した暗闇・煙の中でも場所がわかるように
- (2)○ ポンプ始動を明示する表示灯は箱の内部又は直近(ちゃんと起動したか現場で確認できるように)
- (3)○ 1号消火栓の主配管の立上り管は呼び50mm以上(必要水量を流せる太さ)

設計思想:消防設備は「最悪の日に動くこと」がすべて。No.21(水道直結に頼らない)と同じで、火事の日は水道も電気もアテにならない前提で自前の水源・自前の電源を持つ。

No.46 フロン排出抑制法 — 答え(3)

登場人物と役割分担で整理する

フロン(エアコンの冷媒)を大気に漏らさないための法律。役割は3者に分かれてる。

① 管理者(機器の持ち主=ユーザー)
- 簡易点検の実施(3ヶ月に1回の目視など)
- 定期点検(一定規模以上の機器)
- 点検・整備の記録簿の保存
- 漏えいを確認したら点検・修理

② 充塡回収業者:フロンの充塡・回収(登録業者しかできない)
③ 再生業者:回収されたフロンの再生(許可業者)

問題文の引っかけ
(3)「フロン類の再生の実施」は③再生業者の仕事。管理者の取組事項として法に定められていない=正解。持ち主は「見張って、記録して、直させる」係で、フロンそのものを触る作業は業者の領分。

現場イメージ:店舗や事務所の業務用エアコンの持ち主は全員この「管理者」で、簡易点検の記録は本来オーナー側の義務。実務でもそのまま使う知識。

No.47 建築物省エネ法 — 答え(4)

エネルギー消費性能の対象は「使う設備」

省エネ法が建物のエネルギー消費として計算対象にするのは:

空調・機械換気 / 照明 / 給湯 / 昇降機(+事務機器等)

「空・換・照・湯・昇」で暗唱。

ガス設備はなぜ対象外か
ガス設備(ガス管・メーター)は、エネルギーを運ぶインフラであって、エネルギーを消費する設備じゃない。ガスを使って湯を沸かすなら、それは「給湯設備」の消費としてカウントされる。運び屋と消費者の区別。(4)が規定されていない=正解。

試験テクニック
「対象として規定されていないものはどれか」型は、対象リストを1フレーズで暗唱できれば瞬殺。No.23(公衆便所=便器数)、No.44(現場代理人は載らない)と同じ、仲間はずれ1個系のコスパ問題。

No.48 廃棄物処理法 — 答え(1)

マニフェストは「1個ずつ追跡」するための紙

産業廃棄物管理票(マニフェスト)の目的は、廃棄物が排出→運搬→処分と流れる全行程を追跡して、不法投棄を防ぐこと。だから交付ルールは:

種類ごと・運搬先ごとに交付

がれきはがれきの1枚、廃プラは廃プラの1枚、運搬先がA処分場とB処分場に分かれるならそれぞれに1枚。まとめてドンでは「どのゴミがどこへ行ったか」を追えなくなり、制度の意味がなくなる。(1)「種類にかかわらず一括して交付できる」は誤り。

気付きポイント
(1)「一括交付できる」と(3)「運搬先ごとに交付しなければならない」は正反対のことを言ってる。条文を知らなくても「どちらかが必ずウソ」と絞れる。二択まで来たら、制度の目的(追跡)から考えれば(1)がウソと導ける。

他の選択肢
- (2)○ 廃エアコンのPCB使用部品は特別管理一般廃棄物(細かいが正しい)
- (4)○ 改築で出た衛生陶器(便器等)の破片は産業廃棄物(工事に伴うがれき類)

現場イメージ:解体・改修のたびに書くあの複写式の伝票。電子マニフェストも同じルール。

No.50 機器の据付け — 答え(3)と(4) ※2つ選ぶ

(3)冷却塔の補給水口は高置タンクの低水位より3m以上「下」

冷却塔の補給水はボールタップで自動供給される。ボールタップを動かすにはある程度の水圧が必要で、水圧を生むのは落差。高置タンクの低水位と補給水口が同じ高さだったら、落差ゼロ=水圧ゼロで水が一滴も来ない。だから3m以上下方に据え付ける。「同じ高さとなるように」は誤り。

水は高いところから低いところへ、落差の分だけ圧がつく。給水設計の一番の基本がそのまま問題になってる。

(4)送風機は現場でも心出し調整が必要

送風機は工場で心出し(軸の芯合わせ)調整されて出荷される。でもトラックで揺られ、クレーンで吊られ、現場で据えられる間に微妙にズレる。ズレたまま回すと振動・騒音・軸受の早期摩耗。だから現場で再調整が必要。「現場での調整は不要」は誤り。

「工場でやってあるから現場では不要」系の選択肢は、回転機器についてはほぼウソと思っていい(No.12・22と同じ断定パターン)。

No.51 配管の施工 — 答え(1)と(3) ※2つ選ぶ

(1)飲料用冷水器の排水は「間接排水」

冷水器=飲み水を扱う機器。その排水管を雑排水系統に直接連結したら、排水管が詰まったとき汚水が冷水器側へ逆流して飲み水が汚染される。だから排水口空間(すきま)を開けた間接排水にして、物理的に縁を切る。「直接連結する」は誤り。

これはNo.17(吐水口空間)・No.24(オーバーフロー管)と完全に同じ思想。飲料系の機器の排水はすべて間接排水、と一般化して覚えると3問まとめて取れる。

(3)大便器の汚水管は最小75mm

大便器は固形物が流れる唯一の器具。50mmは洗面器・手洗器レベルの雑排水の管径で、大便器につないだら一発で詰まる。最小75mm。数字の入れ替え引っかけだけど、「固形物が通るから太い」と理由で覚えれば数字を忘れても導ける。

No.52 ダクトの施工 — 答え(2)と(4) ※2つ選ぶ

(2)防火ダンパーの温度ヒューズは用途で3段階

防火ダンパー(FD)は、火災の熱でヒューズが溶けると自動で閉まってダクト経由の延焼を防ぐ。作動温度は:

  • 一般排気:72℃
  • 厨房排気:120℃
  • 排煙:280℃

なぜ厨房が高いか:厨房は調理で普段から熱気ムンムン。72℃設定だと火事でもないのに炒め物の熱気でダンパーが閉まり、排気が止まって厨房が煙だらけになる。誤作動しないギリギリ上の120℃に設定してある。「ともに72℃」は厨房分が誤り。

排煙の280℃も同じ理屈で、排煙ダクトは火災の煙(熱い)を通すのが仕事だから、簡単に閉まってはいけない。

(4)アスペクト比を大きくすると圧損は増える

アスペクト比=長辺÷短辺。同じ断面積でも、正方形(60×60)と細長い長方形(120×30)では周長(壁の長さ)が違う。細長いほど周長が長い=空気が擦れる壁面が多い=摩擦損失が増える。「圧力損失は変わらない」は誤り。

だから(3)の「アスペクト比は原則4以下」というルールがある。(3)と(4)は同じ理屈の表裏で、セットで理解すると忘れない。
